# Modern Tilt Card adaptation

Reference demo: https://strategic-topic-037116.framer.app/

Selected Roles combines the existing spring-based logo parallax with the demo’s gold/lime conic-gradient edge, pointer spotlight, rounded corners, lift, and shadow. Live styles are in role-parallax.css; motion is in role-parallax.js. The demo photo is not used. Company logos remain borderless. Touch devices and reduced-motion users receive stable cards and a static edge.
